This process is most commonly called Metadata-Driven Data Ingestion (or a Metadata-Driven Pipeline).
Instead of writing separate, hardcoded code for every single database table, your script reads a configuration list (the "metadata") to 
dynamically figure out what to fetch and how to fetch it.
Here are the specific terms used for this pattern in data engineering:
1. Metadata-Driven Ingestion
What it means: The code acts like an engine. It reads a control table (like your DBTableConfig_df) to get details like table names, 
active status, and watermarks, then automatically builds and runs the queries.
Why it is used: If you add 10 new tables to the source database tomorrow, you do not need to change a single line of Python code. 
You simply add 10 new rows to your configuration file.
2. Dynamic Query Generation
What it means: The software constructs the SQL statement on the fly using variables.
Example: Your code takes the tablename and watermark from the meta details and strings them together to create a dynamic query:f"SELECT * 
FROM {tablename} WHERE update_date > '{watermark}'"
3. Parameterized Data Fetching
What it means: Passing execution configurations (parameters) into a generic fetching function. Your getDataFromTables(tablename, loadtype, 
watermark) function is a perfect example of this.

audit_log TABLE
---------------
BQ_PROJECT = "avd-databricks-demo"
BQ_AUDIT_TABLE = "avd-databricks-demo.temp_dataset.audit_log"

You must use backticks (`) because your project name contains hyphens (-). In SQL, hyphens are interpreted as subtraction operators unless the 
identifier is wrapped in backticks. You should never use single or double quotes for table names in a CREATE TABLE statement.

Keep your project variable as is, but add backticks to your full table path variable so it is ready to be injected into queries safely:

BQ_PROJECT = "avd-databricks-demo"
# Wrapped in backticks to handle the hyphens safely
BQ_AUDIT_TABLE = "`avd-databricks-demo`.temp_dataset.audit_log" 

##-----------------------------------------------------------------##

The "Create the table" query will not create the dataset. It will only create the table, and it will actually fail with an error if the dataset does not already exist. 
In Google BigQuery, datasets act like folders that hold tables.
BigQuery cannot automatically create a "folder" (dataset) while creating a "file" (table).

1. Why it will fail
If temp_dataset does not exist in your project, BigQuery will return a Not found: Dataset error.

2. How to fix it
You must explicitly create the dataset first before running your table creation query. You can do this by running two separate commands.

-- 1. Create the dataset first
CREATE SCHEMA IF NOT EXISTS `avd-databricks-demo`.temp_dataset;

-- 2. Create the table
CREATE TABLE IF NOT EXISTS `avd-databricks-demo`.temp_dataset.audit_log (
  datasource      STRING,
  tablename       STRING,
  load_timestamp  TIMESTAMP,
  loadtype        STRING,
  record_count    INT64,
  status          STRING
);

##-----------------------------------------------------------------##

Since this is an audit log table that will likely grow continuously, it is highly recommended to add Time-Unit Partitioning on your load_timestamp 
column. This prevents BigQuery from scanning the entire table every time you query recent logs, drastically reducing your query costs.

CREATE TABLE IF NOT EXISTS `avd-databricks-demo`.temp_dataset.audit_log (
  datasource      STRING,
  tablename       STRING,
  load_timestamp  TIMESTAMP,
  loadtype        STRING,
  record_count    INT64,
  status          STRING
)
PARTITION BY DATE(load_timestamp); -- Optimizes cost and performance

from pyspark.sql import SparkSession
from google.cloud import storage, bigquery
from datetime import datetime
import json

# Initialize Spark Session
spark = SparkSession.builder.appName('pullDataFromDB').getOrCreate()

# MySQL Configuration
SQL_CONFIG = {
    "url": "jdbc:mysql://34.132.104.87:3306/hospital_a_db?useSSL=false&allowPublicKeyRetrieval=true",
    "driver": "com.mysql.cj.jdbc.Driver",
    "user": "myuser",
    "password": "mypass"
}

# Google Cloud Storage (GCS) Configuration
GCS_BUCKET = 'healthcare-bucket-22032025'
hospital = 'HospitalA'
LANDING_PATH = f'landing/{hospital}'
ARCHIVE_PATH = f'landing/{hospital}/archive'
dbTableConfig = f'gs://{GCS_BUCKET}/configs/load_config.csv'  #gs://healthcare-bucket-22032025/configs/load_config.csv

# BigQuery Configuration
BQ_PROJECT = "avd-databricks-demo"
BQ_AUDIT_TABLE = f'{BQ_PROJECT}.temp_dataset.audit_log' ##avd-databricks-demo.temp_dataset.audit_log
BQ_LOG_TABLE = f'{BQ_PROJECT}.temp_dataset.pipeline_log' ##avd-databricks-demo.temp_dataset.audit_log
BQ_TEMP_PATH = f"{GCS_BUCKET}/temp/"  

# Initialize GCS & BigQuery Clients
storage_client = storage.Client()
bigquery_client = bigquery.Client()


#-----------------------------------------------------------------------------------#
events = []
def log_event(event_type,message,table = None):
	"""Log an event and store it in the log list"""
	event = {'timestamp' : datetime.datetime.now(),
			'event_type': event_type,
			'message': message,
			'table':table}
	
	events.append(event)
	print(f'{event['timestamp']}  {event_type} - {message}')
	
#-----------------------------------------------------------------------------------#
def uploadLogsToGCS():
	"""Save logs to a JSON file and upload to GCS"""
	LOG_FILE_NAME = f'pipeline_log_{datetime.datetime.now().strftime('%d%m%Y%H%M%S')}.json' ##pipeline_log_27052026203045.json
	LOG_FILE_PATH = f'temp/pipeline_logs/{LOG_FILE_NAME}' ##temp/pipeline_log/log_27052026203045.json
	
	#This function converts your Python objects into JSON
	log_data = json.dumps(events,indent = 4)
	
	BUCKET = storage_client.bucket(GCS_BUCKET)
	blob = BUCKET.blob(LOG_FILE_PATH)
	
	# Upload JSON data as a file
	blob.upload_from_string(log_data,content_type = 'application/json')
	print(f'Logs stored to {GCS_BUCKET}/{LOG_FILE_PATH} for analysis!')
	
#-----------------------------------------------------------------------------------#
def uploadLogsToBQ():
	"""Save logs to BigQuery"""
	if events:
	spark.createDataFrame(events).write.format('bigquery').option('table',BQ_LOG_TABLE).option('temporaryGcsBucket',BQ_TEMP_PATH).mode('append').save()
	print('Logs stored in BQ for analysis!')

# Function to Get Latest Watermark from BigQuery Audit Table
def getLastUploadDate(tablename):
	
	query = f"""
			SELECT MAX(load_timestamp) as LastUploadDate
			FROM `{BQ_AUDIT_TABLE}`
			WHERE tablename = '{tablename}' AND data_source = 'HospitalA'
			"""
	
	date = bigquery_client.query(query).result()
	
	#Google Cloud BigQuery client library returns query results as an iterable collection of rows, even if your SQL query only calculates a single value (like MAX).
	#The .result() method returns a RowIterator object. Even though SELECT MAX(...) guarantees exactly one row of output, Python's BigQuery client does not automatically unpack 
	#that row. The for _ in date: loop is a safe way to step into that collection and grab the first available row.
	
	for _ in date:
		return _.LastUploadDate if _.LastUploadDate else '01-01-1970 00:00:00'
	return '01-01-1970 00:00:00'
	
	#A Cleaner Alternative
	#You can make this code more readable by fetching the next available row directly using Python's built-in next() function:
	# Safely get the first row, default to None if empty
	#first_row = next(iter(date),None)
	
	#if first_row and first_row.LastUploadDate:
		#return first_row.LastUploadDate
	#return '1970-01-01 00:00:00'

# Function to Move Existing Files to Archive
def moveExistingFilesToArchive(tablename):
	# 1. Initialize the GCS Bucket object
	BUCKET = storage_client.bucket(GCS_BUCKET)

	#In Google Cloud Storage (GCS), the prefix parameter acts like a search filter that limits your scan to a specific folder path.
	#Without the prefix parameter, list_blobs() would scan every single file inside your entire bucket
	blobs = BUCKET.list_blobs(prefix=f'landing/{hospital}/{tablename}/')
	
	#.name returns the file path of a bucket object as a plain string, excluding the gs:// protocol and the bucket name.
	#When you scan a bucket, GCS returns full metadata objects for every file it finds. Using .name strips away all the heavy metadata (like file size, creation time, and 
	#content type) and gives you just the file path string so you can check if it ends with .json.
	
	for blob in blobs:
		if blob.name.endswith('.json'): #landing/HospitalA/patients/patients_27052026.json
			ARCHIVE_FILE = blob.name.split('/')[-1] #patients_27052026.json
			
			ddmmyy = ARCHIVE_FILE.split('_')[-1].split('.')[0] #27052026
			dd = ddmmyy[:2]  ##27
			mm = ddmmyy[2:4] ##05
			yy = ddmmyy[-4:] ##2026
			
			# Move to Archive
			DESTINATION_FILE = f'{ARCHIVE_PATH}/{tablename}/{yy}/{mm}/{dd}/{ARCHIVE_FILE}'  #landing/HospitalA/archive/patients/2026/05/27/patients_27052026.json
			
			# Copy file to archive and delete original
			BUCKET.copy_blob(blob,BUCKET,DESTINATION_FILE)
			
			blob.delete()
			log_event('INFO',f'{ARCHIVE_FILE} moved to {DESTINATION_FILE}' ,table=tablename)

# Function to Extract Data from MySQL and Save to GCS
def getDataFromTables(tablename,loadtype,watermark):
	try:
		if loadtype.lower() == 'full':
			query = f'`{tablename}`'
			
		elif loadtype.lower() == 'incremental':
			LastUploadDate = getLastUploadDate(tablename)
			log_event('INFO',f'Last time table updated for {tablename} on {LastUploadDate}',table=tablename)
			
			#SQL subquery requirement for JDBC: When passing a raw SELECT query to a JDBC dbtable option, the database engine requires the query to be wrapped in parentheses and 
			#given an alias.
			
			#Missing quotes in the SQL query: In your incremental block, your date string {LastUploadDate} will resolve to something like 1970-01-01 00:00:00.
			#SQL engines will treat this as syntax errors or mathematical subtractions unless you wrap it in single quotes: '{LastUploadDate}'.
			

			query = f"""
					(SELECT *
					FROM `{tablename}`
					WHERE `{watermark}` > '{LastUploadDate}') AS incremental_data;
					"""
		
		else:
			raise raise ValueError(f"Invalid loadtype provided: '{loadtype}'. Expected 'full' or 'incremental'.")
			
		#.save() vs .load(): You are trying to read data into a DataFrame. At the end of a read operation, you must use .load(),.save() is only used when writing data out.
		
		#Missing quotes in options: Options like user, password, url, driver, and dbtable are written as variables instead of strings. They must be enclosed in quotes (e.g., 'url', 'dbtable').
		
		#Missing Python line continuations: PySpark method chaining (.option().option()) across multiple lines requires wrapping the entire expression in parentheses () or 
		#using a backslash \ at the end of each line.
		
		TableData_df = (spark.read.format('jdbc')
							.option('user',SQL_CONFIG['user'])
							.option('password',SQL_CONFIG['password'])
							.option('url',SQL_CONFIG['url'])
							.option('driver',SQL_CONFIG['driver'])
							.option('dbtable',query)
							.load())
		
		log_event('SUCCESS',f'Successfully extraced data for table {tablename}',table=tablename)
		
		BUCKET = storage_client.bucket(GCS_BUCKET)
		FILE_NAME = f'{tablename}_{datetime.now().strftime('%d%m%Y')}.json' #patients_27052026.json
		FILE_PATH = f'{LANDING_PATH}/{tablename}/{FILE_NAME}' #landing/HospitalA/patients/patients_27052026.json
		blob = BUCKET.blob(FILE_PATH)
		blob.upload_from_string(TableData_df.toPandas().to_json(orient='records',lines = True),content_type = 'application/json')
		
		log_event('SUCCESS',f'Successfully uploaded data to {GCS_BUCKET}/{FILE_PATH} for table {tablename}',table=tablename)
		
		data = [('HospitalA',tablename,datetime.datetime.now(),loadtype,TableData_df.count(),'SUCCESS')]
		columns = ['datasource','tablename','load_timestamp','loadtype','record_count','status']	
		
		audit_df = spark.createDataFrame(data,schema = columns)
		
		# Insert Audit Entry
		(audit_df.write.format('bigquery')
					.option('table',BQ_AUDIT_TABLE)
					.option('temporaryGcsBucket',GCS_BUCKET)
					.mode('append')
					.save())
		
		log_event('SUCCESS',f'Audit log updated for the table {tablename}',table=tablename)
		
	except Exception as e:
		print(f'Error fetching data from table {tablename}: {str(e)}')
		log_event('ERROR',f'Error reading table {tablename} : {str(e)}', table=tablename)
		
	
#-----------------------------------------------------------------------------------#
# Function to Read Config File from GCS
def getDBTableConfig():
	log_event('INFO','SUCCESSFULLY READ THE TABLE CONFIG FILE.')
	return spark.read.csv(dbTableConfig,header = True)

#database				datasource		tablename		loadtype	watermark	is_active	targetpath
#hospital-a-mysql-db	hospital_a_db	encounters		Incremental	ModifiedDate	1		HospitalA
#hospital-a-mysql-db	hospital_a_db	patients		Incremental	ModifiedDate	1		HospitalA
#hospital-a-mysql-db	hospital_a_db	providers		Full						1		HospitalA
#hospital-a-mysql-db	hospital_a_db	departments		Full						1		HospitalA
#hospital-b-mysql-db	hospital_b_db	encounters		Incremental	ModifiedDate	1		HospitalB
	
# read config file
DBTableConfig_df = getDBTableConfig()
for row in DBTableConfig_df.collect():
	if row['datasource'] == 'hospital_a_db' and row['is_active'] == '1':
		#database,datasource,tablename,loadtype,watermark,is_active,targetpath = row
		#However, when pulling a column by name from a PySpark Row object using string indexing (like row['datasource']), it is 
		#case-sensitive and relies on the precise header text.More importantly, directly unpacking the row with database, 
		#datasource, ... = row (p. 7) right inside the block will crash if the order or number of columns in the CSV does not match perfectly. 
		#It is significantly safer and cleaner to access everything directly from the row object.
		
		tablename = row['tablename']
		loadtype = row['loadtype']
		watermark = row['loadtype']
		
		moveExistingFilesToArchive(tablename)
		getDataFromTables(tablename,loadtype,watermark)

uploadLogsToGCS()
uploadLogsToBQ()
