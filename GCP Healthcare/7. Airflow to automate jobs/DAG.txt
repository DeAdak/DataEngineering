An Apache Airflow DAG (Directed Acyclic Graph) structure is a collection of all the tasks you want to run, organized in a way that reflects 
their relationships and dependencies. Written in standard Python, an Airflow DAG file does not perform actual data processing; instead, 
it serves as a configuration file defining the layout, sequence, and execution rules of your workflow

The 5 Core Components of a DAG File:

1. Library Imports
#Every DAG script begins by importing the core components, operators, and required date utilities.
from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.bash import BashOperator
from airflow.operators.python import PythonOperator


2. Default Configuration Arguments
A Python dictionary defines settings that are automatically passed down and applied to all tasks within the DAG, keeping the code clean 
and maintainable.

default_args = {
    'owner': 'data_team',
    'depends_on_past': False,
    'email_on_failure': False,
    'retries': 2,
    'retry_delay': timedelta(minutes=5),
}


3. The DAG Context Instantiation
The DAG object defines global properties like its unique identifier, execution frequency, and activation timeline. You can declare it 
explicitly or leverage Python's context manager (with statement) to automatically associate nested tasks with the DAG.

with DAG(
    dag_id='e_commerce_etl_pipeline',
    default_args=default_args,
    description='Daily extraction and loading of retail transactions',
    schedule_interval='@daily',
    start_date=datetime(2026, 1, 1),
    catchup=False,
    tags=['retail', 'etl']
) as dag:


4. Task Definitions via Operators
Tasks represent the specific units of work (the nodes in your graph). They instantiate operators, which act as predefined templates for 
execution logic.
    
	def clean_raw_payload():
        print("Scrubbing invalid entries...")

    task_download = BashOperator(
        task_id='download_csv_files',
        bash_command='curl -sS https://example.com -o /tmp/data.csv',
    )

    task_transform = PythonOperator(
        task_id='transform_payload',
        python_callable=clean_raw_payload,
    )


5. Graph Topology (Task Dependencies)
Dependencies establish the directed edges of your graph, explicitly commanding Airflow which tasks must complete before others are 
allowed to start.

# Configures task_download to run completely before task_transform starts
task_download >> task_transform
